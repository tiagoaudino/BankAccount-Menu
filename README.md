# BankAccount-Menu
# Sistema Bancário em Java

Projeto desenvolvido para praticar Programação Orientada a Objetos.

## Funcionalidades

- Criar conta
- Depositar
- Sacar
- Transferir valores
- Consultar saldo

## Conceitos utilizados

- Classes e Objetos
- Encapsulamento
- Métodos
- Construtores
- Scanner
- Estruturas de decisão
